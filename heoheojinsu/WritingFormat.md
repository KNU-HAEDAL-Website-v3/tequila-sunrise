# 1. 제목 작성 방법
- `#` : 메인 제목 (H1)
- `##` : 부제목 (H2)
- `###` : 소제목 (H3)
- `####` : 세부 소제목 (H4)
- `#####` : 세부 소제목 (H5)
- `######` : 세부 소제목 (H6)

# 2. 항목 수준별 기호 사용법
- 대항목: "1."
- 중항목: "가."
- 소항목: "1)"
- 세소항목: "가)"
- 더 상세한 하위 항목을 구성해야할 경우, 다음과 같은 기호를 사용한다. "(1)", "(가)"

# 3. 표 작성 방법
- 표를 작성해야 할 경우, 다음과 같은 형식을 사용한다.

## 가. 항목별 특징 요약표
```markdown
| 구분 | 특징1 | 특징2 | ... | 비고 |
| --- | --- | --- | --- | --- |
| 항목1 | 내용1_1 | 내용1_2 | ... | 내용1_n | 비고1 |
| 항목2 | 내용2_1 | 내용2_2 | ... | 내용2_n | 비고2 |
```

## 나. 요소 간 차이 요약표
```markdown
| 구분 | 요소1 | 요소2 | ... | 비고 |
| --- | --- | --- | --- | --- |
| 특징1 | 내용1_1 | 내용1_2 | ... | 내용1_n | 비고1 |
| 특징2 | 내용2_1 | 내용2_2 | ... | 내용2_n | 비고2 |
```

# 4. 이미지 삽입 방법
- 이미지를 삽입해야 할 경우, 다음과 같은 형식을 사용한다.

## 가. 본문에 포함하여 첨부하는 경우
```markdown
![alt text](image.png)

그림 1. 이미지에 대한 간략한 설명
```

## 나. 별도로 첨부하는 경우
- 파일의 경로는 프로젝트 루트 디렉토리를 기준으로 작성한다.
- 이미지 파일명에 공백이 포함되어 있을 경우, 언더스코어("_")로 대체한다.

# 5. 순서 없는 목록 작성 방법
- 순서 없는 목록을 작성해야 할 경우, 다음과 같은 형식을 사용한다.

```markdown
- 목록1
- 목록2
- 목록3
```

# 6. 순서 있는 목록 작성 방법
- 순서 있는 목록을 작성해야 할 경우, 다음과 같은 형식을 사용한다.

```markdown
1. 목록1
2. 목록2
3. 목록3
```

# 7. 인용 문구 작성 방법
- 인용 문구를 작성해야 할 경우, 다음과 같은 형식을 사용한다.

```markdown
> 인용 문구

인용문 아래에 출처를 명시한다. (출처: 이름)
```

# 9. 링크 삽입 방법
