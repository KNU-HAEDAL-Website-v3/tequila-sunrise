# 1. 문장 서술 방식
- 구체적인 내용: 서술식
- 세부 요소: 개조식

## 가. 상세한 설명이 필요한 경우 (두괄식)
- 결론을 먼저 제시한다.
- 결론에 대한 근거를 제시한다.
- 추가 설명을 한다.

## 나. 요약이 필요한 경우 (미괄식)
- 근거를 먼저 제시한다.
- 부연 설명을 한다.
- 마지막에 결론을 제시한다.

## 다. 전달하고자 하는 핵심 내용을 정확하게 파악할 수 있는 경우 (중괄식)
- 핵심 내용을 중간에 제시한다.
- 핵심 내용에 대한 근거를 제시한다.
- 추가 설명을 한다.

# 2. 문단 구성 방법

## 가. 단일 문단
- 내용이 간결하고 명확한 경우 사용한다.

## 나. 복수 문단
- 내용이 복잡하고 다양한 경우 사용한다.
- 각 문단은 하나의 주제를 다룬다.
- 문단 간의 연결은 매끄럽게 이어진다.

# 3. 문장 규칙

## 가. 능동태 사용
- 문장은 능동태로 작성한다.

## 나. 수동태 사용 금지
- 문장은 수동태로 작성하지 않는다.

## 다. 높임말 사용
- 문장은 높임말을 사용한다.

## 라. 간결한 문장 사용
- 문장은 간결하고 명확하게 작성한다.

## 마. 비문 사용 금지
- 문장은 비문으로 작성하지 않는다.

# 4. 문단과 문장 구성 규칙

## 가. 문단의 내용
- 한 문단은 하나의 주제를 다룬다.

## 나. 문단의 연결
- 문단은 매끄럽게 연결된다.

## 다. 문장의 길이
- 문장은 간결하고 명확하게 작성한다.
- 문장은 20자 이내로 작성한다.

# 5. 강조 방법

## 가. 결론을 강조하는 경우
- 결론을 강조한다.
- 결론을 반복한다.
- 결론을 명확하게 제시한다.

## 나. 근거를 강조하는 경우
- 근거를 강조한다.
- 근거를 반복한다.
- 근거를 명확하게 제시한다.

## 다. 추가 설명을 강조하는 경우
- 추가 설명을 강조한다.
- 추가 설명을 반복한다.
- 추가 설명을 명확하게 제시한다.

# 6. 작성 규칙

## 가. 인용
- 인용은 100자 이내로 작성한다.

## 나. 줄바꿈
- 줄바꿈은 띄어쓰기 2칸을 한다.

## 다. 문장 연결
- 문장은 매끄럽게 연결된다.
